# Master plan

1. Preserve stock Fire OS and keep the physical device untouched. Use a public cloud repository and standard free Ubuntu runners only; no local SDKs, build caches, emulators, paid services or external paid APIs.
2. Preserve the already-successful untouched upstream baseline with exact commit/license/signature evidence.
3. Produce an independent minimum-permission native API25 app, its source, tests, reproducible build and signed development APK.
4. Establish supervised physical navigation/performance/firmware evidence before claiming hardware compatibility.
5. Improve Home/top-shelf and module separation; finish exhaustive firmware analysis, categories and focus restoration.
6. Add only feasible optional Apple ecosystem modules after protocol, license, ABI and API review.

Do not treat this preview as completion of the full operating-environment mission. APK correctness and honest evidence outrank visual breadth. Source and reports are checkpointed in Git; actual release assets remain in GitHub. Mandatory resource/quota/payment blockers stop work and require explicit continuation.
