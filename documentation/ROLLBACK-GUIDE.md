# Rollback

The preview does not become the default HOME, start on boot, disable Amazon packages or change settings automatically. Press the Fire TV remote Home button to return to Amazon, or Back twice from MantisTV Home to exit.

To remove it, use Fire OS Settings > Applications > Manage Installed Applications > MantisTV > Uninstall. Alternatively, in a separately authorized supervised local test session: adb uninstall dev.mantistv.home.

Uninstalling deletes MantisTV local profiles, favorites, watchlists and recent-launch history. Review that consequence before uninstalling. No factory reset, firmware restore, root, DNS change or system-package repair is part of rollback.
